# 一次性历史迁移

这是上线切换任务，独立于日常产品功能。当前个人版发布不包含真实历史数据或迁移入口。

迁移需从经过核验的旧库中明确选定本人 employee_id；只选择本人的 completed 服务、关联明细及所需项目/规则版本。旧账号、其他同事资料、Session、密码、注册码、结算文件均不能进入个人库。保存原项目收入、计薪分钟、规则编号和服务汇总，不按新规则重算。

必须在最终 GitHub Pages 地址对应的 iPhone 数据库中导入。不能先写入 localhost 或另一个预览网址并期望其自动出现在正式地址；也不能将个人数据作为公开 seed、JS、JSON 或缓存文件部署。

下一阶段需实现并核验临时私密传输通道、空库检查、编号映射、事务导入、重复导入防护和逐月对账。任何失败保持旧系统和手机原数据不变。此通道结束后撤除，不留下日常文件导出或恢复功能。

完成记录数、逐月收入、计薪分钟和明细快照对账，并由用户确认 iPhone 实机使用后，再下线旧业务系统。旧团队服务器和数据库当前未被修改。
