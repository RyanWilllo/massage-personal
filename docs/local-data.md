# 本地数据

数据库：`massage-personal`，当前 schema 1，store `state`，主键 `personal`。

状态包含：projects（项目/时长/启停）、versions（基准时薪和项目计薪规则）、services（记录及明细快照）、三个自增编号。没有账号、employee_id、绑定姓名、月结或文件表。

读操作返回独立的结构化副本；写操作在一个事务内读取、验证、计算、保存。事务失败不会消费编号或留下半张服务。空间不足和打开失败展示可重试错误，不显示保存成功。

软件使用 Cache Storage 保存公开程序资源，用 IndexedDB 保存业务状态，两者不混存。请求持久存储以减少浏览器主动淘汰的可能，但不构成数据备份。

用户已决定取消所有导出和备份恢复。清理站点数据、丢失设备或改变网址可能导致无法访问原记录。版本升级不得通过删库重建实现。

迁入空库保护与新迁入保存核对使用按对象键排序的规范化 JSON，忽略对象字段顺序，保留数组顺序、字段类型、数值和全部自增编号。迁入标记保存原始传输哈希和规范化内容哈希；旧标记继续采用原校验。真实修改、已删除的录入历史或既有迁入标记仍阻止覆盖。

本人明确允许删除手机测试记录后迁入。替换仅在迁入页明确选择，源验证通过后与保存旧记录在同一事务完成；以预览时的状态签名检测并发变化。规则或项目的独立修改、已迁入标记继续阻止替换，不提供通用清库或恢复功能。
